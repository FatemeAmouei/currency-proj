Currency-Proj

این پروژه یک وب‌اپلیکیشن برای تبدیل ارز است که با استفاده از React و TypeScript ساخته شده است.

هدف این پروژه ارائه یک ابزار آنلاین برای تبدیل ارزها با استفاده از اطلاعات نرخ‌های روز به‌صورت داینامیک است.



تکنولوژی‌ها و ابزارهای استفاده شده:

React و TypeScript: برای پیاده‌سازی رابط کاربری و مدیریت داده‌ها

API ارز: برای دریافت اطلاعات نرخ ارز به‌روز
tailwind: استایل دهی واکنش گرا

ویژگی‌ها:

تبدیل ارز به صورت آنلاین

طراحی واکنش‌گرا برای استفاده در دستگاه‌های مختلف

استفاده از API برای دریافت اطلاعات نرخ ارز

به‌روزرسانی نرخ ارز و طلا به صورت آنلاین از منابع معتبر.



وضعیت پروژه:

در آینده قسمت‌ها و گزینه‌های بیشتری به آن اضافه خواهم کرد. در حال حاضر فقط بخش اصلی نوشته شده است.
